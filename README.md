# Iris Flower Classification using Machine Learning

## Project Overview
This project uses Machine Learning to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

The prediction is based on four flower measurements:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Dataset
The Iris dataset contains 150 flower samples, four input features, and three target classes.

## Machine Learning Algorithms
Two classification algorithms were implemented:
1. K-Nearest Neighbors (KNN)
2. Decision Tree Classifier

## Model Performance

| Algorithm | Accuracy |
|---|---:|
| KNN | 100% |
| Decision Tree | 93.3% |

KNN performed better on the selected test dataset.

## Sample Prediction
The KNN model successfully predicted Iris Setosa using the sample measurements:
`[5.1, 3.5, 1.4, 0.2]`

## Conclusion
This project demonstrates how Machine Learning classification algorithms can identify Iris flower species using their measurements. KNN achieved the highest test accuracy in this experiment.
